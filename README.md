# bonefracture

IEEE-style production codebase for **Medical Image Analysis for Bone Fracture Detection Using Deep Learning**.

Enter the application tree:

```bash
cd bone_fracture_system
pip install -r requirements.txt
python app.py
```

Full documentation, class lists, training commands, and clinical safety notes live in [`bone_fracture_system/README.md`](bone_fracture_system/README.md).
