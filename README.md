# Bone Fracture Classification (Project)

This repository starts from the IEEE Access 2025 baseline paper on bone-fracture X-ray classification (VGG-16, VGG-16 + Random Forest, ResNet-50 + SVM, EfficientNetB0 + XGBoost).

**Full paper review, limitations, and the new proposed project (architecture, experiments, modules, viva notes):** see [`BASE_PAPER_REVIEW_AND_PROPOSED_WORK.md`](BASE_PAPER_REVIEW_AND_PROPOSED_WORK.md).

## Base paper

S. Torne et al., “VGG-16, VGG-16 With Random Forest, Resnet50 With SVM, and EfficientNetB0 With XGBoost—Enhancing Bone Fracture Classification in X-Ray Using Deep Learning Models,” *IEEE Access*, 2025. DOI: [10.1109/ACCESS.2025.3534818](https://doi.org/10.1109/ACCESS.2025.3534818)
