Base paper

Torne et al., IEEE Access 2025: VGG-16 / RF / ResNet-50+SVM / EfficientNetB0+XGBoost, 1,129 images, 10 morphology classes, classification only (~95% on 140 test images).

This system

  • YOLOv8 detection (where the fracture is) plus 7 anatomical classes from the original abstract.
  • Training corpus target ≥ 20,000 images (GRAZPEDWRI-DX + MURA + FracAtlas + Roboflow + Kaggle morphology, plus a 20,000-image phantom set for software delivery).
  • Flask + HTML/CSS/JS web CAD for preliminary screening.
  • Optional hybrid classifiers reproducing the base-paper heads on morphology labels.
